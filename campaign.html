Game mode

Campaign

Linking games together instead of playing them one-off: what happened in the last game should matter in the next one.

In development

The campaign mode does not have written rules in the project yet. What follows is the outline of what is being considered, not playable rules. Once they exist, they will be published here and linked from the army builder.

The idea

A campaign is a series of games between the same armies, where the result of each one leaves its mark on the next. Instead of rebuilding the list from scratch every time, you start from the one you brought and adjust it.

What is being considered

  • Army continuity. The same base list across the campaign, with a points limit that can grow between games.
  • Consequences for casualties. A hero who falls should not simply be back as good as new in the next game.
  • Hero progression. Surviving and winning should leave something behind: some bounded upgrade, not a snowball.
  • Linked scenarios. The winner chooses or shapes the next scenario.

None of these points is settled. Do not use them as rules.

In the meantime

Everything you need for one-off games is already here: build the list in the army builder, save it in lists and use the game tracker at the table. Saving several versions of the same list is, for now, the most practical way to run a campaign by hand.
